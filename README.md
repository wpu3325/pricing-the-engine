# Pricing the Engine

A deal tool for an enterprise reinforcement-learning (RL) post-training engagement, built for the Applied Compute take-home. It turns a customer request into the cost to deliver, the price, the margin, and a proposal and statement of work.

**Start here: https://wpu3325.github.io/pricing-the-engine/** (the deliverables hub; every page below is linked from it).

| Deliverable | What it is | Link |
|---|---|---|

The default example (*Example Enterprise*, three RL cycles, one open-weight model) has a delivery cost of **$106,590**, a quote of **$210,000** and a margin of **49.2%**. It is on **HOLD** until the model benchmark, training licence and GPU rate are confirmed, so the quote is not ready to send.

## Run and verify

```bash
npm install
npm run verify     # re-extract the workbook, rebuild every page, run all tests
npm start          # serve the site locally at http://localhost:8080
```

`npm run verify` runs the parity suite (17 scenarios recalculated in LibreOffice from the supplied workbook), the acceptance tests, customer-safety tests, link checks, and a freshness check: every published page is rebuilt from the engine and must match the file on disk. `npm run build` rebuilds the app and the deliverables without tests.

`app/index.html` is a self-contained file, so the tool also works by opening it directly.

## Repo

- `index.html`: the hub, generated by `scripts/build_deliverables.mjs`.
- `app/`: the live tool, bundled from `src/` by `scripts/build.mjs`.
- `deliverables/`: the generated pages and the downloads (`downloads/`).
- `docs/`: source notes in Markdown: the walkthrough, COGS ledger, pricing rationale and parity log.
- `data/`: catalogue, presets and the workbook dump (`workbook_dump.json`).
- `archive/`: the original configurator notes and brief, kept for reference.
- `test/` and `e2e/`: the tests.

## Limits

Throughput (100,000 tokens per GPU-hour) is a proxy and the largest unknown. Rates, labour and margin policy are illustrative. The final holdout evaluation is not costed. Legal text is placeholder. The full list is on the [hub](https://wpu3325.github.io/pricing-the-engine/) and in [PARITY.md](docs/PARITY.md).
