How the pieces agree

  • The workbook’s own formulas were recalculated in LibreOffice for 17 scenarios; the engine matches every mapped cell to 1e-6. Parity table · PARITY.md
  • Customer documents (proposal, SOW) are generated without cost, margin or labour rates. A test fails the build if one ever includes them.
  • Every number on this page is read from the engine when the site is built. npm run verify rebuilds the site and fails if a number or a link is stale.

Known limits, stated up front

  • Throughput is a proxy (100,000 tokens per GPU-hour in the workbook; 1,000,000 as the usage-model placeholder). Until it is measured, Ari token prices are provisional and the quote is held.
  • Rates, labour, extension costs and margin policy are illustrative. The workbook’s $3.99 H100 price is an expired promotion; list is $5.49.
  • The final holdout evaluation is not costed, so the handoff margin is overstated.
  • The deck and GTM PDFs in the original pack carried different figures ($112,097 COGS against the workbook’s $106,590). They are not used; the workbook is canonical. See PARITY.md §3.
  • Legal text is placeholder; bracketed items need counsel review.
